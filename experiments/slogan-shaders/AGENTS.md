# 口号样例接续

本页是Hi首页口号的六种材质对照工具，使用同一 `../../src/scripts/slogan-effects.js`。事实源见README与 `../../docs/design/2026-10-09-shaders/README.md`，发布状态回根CURRENT。

本目录npm管理Vite，根pnpm管理正式站和共享Shaders依赖。先在Hi根安装依赖，再本目录npm ci。npm run dev端口4329，npm run build构建；不注册常驻。canvas必须内联100%尺寸，resize按真实h1字形重建。验证自动成形往返、模式切换、暂停、窄屏、主题、减少动态与回退。修改共享引擎需同时回归首页与对照页。
