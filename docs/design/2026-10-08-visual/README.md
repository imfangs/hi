# Hi · 视觉作品选集

2026-10-08。方帅在上一轮交互改进后明确提出：Hi体现品味，视觉也应提升。本轮由格得选择并实施视觉方向；没有把Agent选择记录为用户已认可的审美反馈。

## 视觉来源与决定

- 实际查看了 [Pentagram Work](https://www.pentagram.com/work) 的大小作品并置，以及 [Frank Chimero / Dust](https://frankchimero.com/projects/dust/) 的个人空间与独立作品画幅。截图范围、访问边界与实际观察见 [REFERENCES](REFERENCES.md)。引用的是具体视觉机制，未复制其作品、标志或站点。
- 通过FBT以当前Hi、Pentagram截图与两张真实作品封面为输入，生成两张概念。选择 [editorial-atelier](concepts/editorial-atelier.png)：斜体署名、独立题签、大图与不等宽组合。另一个 [printed-index](concepts/printed-index.png)作为对照保留。
- 概念是构图与字体方向，不是逐像素规格。实际网页保留完整原图和真实文案；模型重绘的界面、错误日期与文字不进入产品。主代理与独立视觉评审均看过原图与实现。

## 最终展陈

默认首页以晨间花园开场，随后把菌侠原稿与柚子的小岛并置，再穿插工具、阅读和短片。大小、位置和编号属于视觉展陈，不代表投资优先级、使用量、发布时间或用户管理标记。`src/lib/exhibition.ts` 是顺序与尺度的唯一配置，未知作品按原顺序追加；17份MDX的原始order、文案、链接和原图均保留。

桌面采用少量12列组合，晨间花园与短片有独立题签；后半回到更安静的作品目录。分类/搜索时恢复规整双列，手机始终单列，避免CSS order/dense造成键盘顺序错位。图片和题签是两条等价站内入口，共享view/q；键盘保留一个主入口，外部体验链接独立。

Taste使用自托管Instrument Serif斜体，Build/Sell及工具文字继续Geist，中文标题/阅读继续宋体。字体来源与OFL见 [font-source](font-source.json)。纸白、墨色、朱砂、TBS和掌心之光继续使用；取消重复的卡片底板、状态圆点与按钮框，把视觉重量交给作品。

详情采用更宽的图像舞台、较大的标题与窄栏简介，正文仍保持680px阅读宽。原生媒体的控制、画幅与按需加载不变。

## 验证范围

使用Codex内置浏览器，真实操作搜索/分类、图片入口、原位返回/焦点、空结果、历史与主题；检查390/701/800/960/1001/1440px控件几何与完整8:5图像，另走过全部17详情的1440与320px布局。关闭脚本后17件作品与15个外部入口仍可用；随后恢复脚本，减少动态测试也已恢复。

截图曾在手机切桌面时取得462×1000的过渡画面；重新导航后核对PNG确为1440×1000，再用于对照。播放器属性使用实际HTML属性读取；一轮属性代理未返回playsInline的结果没有被当作产品缺陷。媒体24处控制/内联/按需/不自动播放均保留；本轮没有重新完整观看所有影片。

真实设备、Safari、真人输入法和真实访客审美反馈尚未新增验证。所有概念、来源和QA材料留在docs；公开构建只含实际界面、原作品媒体与新字体。

外链新标签接管未被IAB回读到；随后用CUA Chrome实际点击首页花纸入口，确认新标签到达晨间花园并保留原页，两个临时Chrome页均已关闭。没有据IAB工具限制推断产品链接成功或失效。
