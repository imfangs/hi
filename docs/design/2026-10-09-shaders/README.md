# 随机口号材质

2026-10-09。方帅要求将三种样例放入Hi，每次打开随机展示，成形不定时0–100往返，并增加更鲜明的效果。

首页随机从墨色、成形、回响、极光、熔彩、棱镜六种中选一种。尺寸、主题变化保持当前类型；新打开/刷新重新选择，随机可能重复。首页和对照页共用 `src/scripts/slogan-effects.js`，不复制动画逻辑。

## 实现与取舍

- HTML h1先显示，异步导入 `shaders@4.0.3` 后渐进增强。GPU绘制范围限制在字形内；真实h1及三个词决定布局和换行，读取本地字体/各词位置制作遮罩。图集位置不因加载效果变化。
- 成形初始完整；等待2.5–6秒后开始100→0，约2.4秒，0端停250ms后返回100；完整端停4.5–10秒再往返。后台、离屏和暂停不累计时间。
- 回响点击/Enter改变波源并启动约2.6秒动画；棱镜点击改变折射点。其余按自身材质运动，墨色可指针描画。
- 减少动态或无WebGPU时保留静态文字；加载失败、GPU失败亦回退。显式关闭遥测。右下角有暂停/继续，pagehide销毁、pageshow恢复；resize重建纹理与实例，颜色随主题更新。
- 首页控制代码gzip约3KB，GPU引擎独立延迟块gzip约714KB。没有把组件库内联进首屏阻塞脚本；详情没有口号脚本。仍有一次性下载成本，未声称已实现按组件裁剪。
- MIT许可随 public/shaders-LICENSE.txt发布；全部效果为基础组件自组，未使用平台付费预设。
