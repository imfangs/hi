- 首页保留 TASTE / BUILD / SELL 三词同列：IdleSlogan.astro 与 idle-hero.js，在黑色舞台依次循环全部37种效果（首版八种筛选已按方帅后续要求撤销），离屏、后台和手动暂停时停止帧调度，减少动态偏好直接显示完整静止字标。
- `/omarchy/`：完整 37 种效果 × 三字标，选播、连播、随机、全屏/沉浸，以及返回作品集与旧日字光入口。署名 Omarchy 与原作者 ChrisBuilds，MIT 许可随站发布。

- Hi 持有正式网页适配与部署；idle-type 保留生成脚本和初版探索。原实验源提交 5a68ad5，未来重新生成只更新录制/manifest，不覆盖 Hi 的播放器与页面。

## 对标与有意差异

Omarchy 源码固定 33783b1707d2fd5cdbab99aec183fc761d14bca0，ttfx 是 ChrisBuilds TTE 的 Rust 移植。本项目由 TTE 0.15.0 离线生成，60Hz 引擎步進、30fps 帧录制，保留原运动与配色。每效果/字标为固定轨迹，随机仅改变播放选择；不声称与终端120fps完全一致。

保持黑底、块状字模、留白与同列三词；首页作品集、十九项内容、封面和搜索/返回行为保留。独立页开放全效果库，避免让首页承担完整控制面板。

## 实践发现

Astro preview 会给 .json.gz 附 Content-Encoding:gzip，fetch 已自动解压；Python 简单静态服务则原样返回压缩体。初版重复解压导致首页回退，现按响应内容 gzip magic 检查，支持两类服务器。verify-idle-recordings.mjs 对真实文件覆盖这两种响应，避免依赖特定托管行为。

中文新增15字，按固定官方字体来源重建两份子集，956汉字；同步CSS内容hash查询参数，避免旧缓存缺字。
