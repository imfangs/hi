# Hi · 标杆设计升级

2026-10-08。方帅要求使用 FBT 标杆设计法提升 Hi 的 UI 和交互。基线为 `af66be9`（运行源码 `f64523f`），17件作品；实施依据与官方原文见 [SOURCES](SOURCES.md)。最终发布身份回 [CURRENT](../../../CURRENT.md)。

## 产品判断

Hi 是让访客发现、观看和尝试真实作品的地方。既有纸白、中文宋体、Geist、TBS和真实封面已经形成气质。本轮保持这些选择，把投入放在作品增至17件之后的持续浏览：随时换分类、按名称或用途查找、直接体验、看完介绍回到原位置。

Apple HIG 的按钮与搜索说明、GOV.UK 的返回状态原则提供机制依据；它们都是本次回读的官方文字，不是对其当前界面的视觉模仿。固定工具栏、真实缩略图推荐及具体版式是Hi自己的适配。

主代理与独立评审均看过受控对照：分类当前态由细线变成明确的墨色选择，搜索范围可见，纸白/宋体与真实封面仍是主体；详情保留原主动作，底部继续浏览有可识别的作品画面。小字事实另回DOM，不以联系表替代文本核查。

工具栏和直接入口增加部分页面高度；即使收紧开场，本轮也不宣称“整页更紧凑”或“少滚动”。已验证的是可触达、路径和状态恢复；真实访客偏好、任务耗时与转化仍未验证。没有新真实手机、Safari或真人中文输入法验收；组合输入检查使用浏览器合成事件。

## 验收与接续

[本地回执](../../releases/2026-10-08-benchmark-local.json)记录构建、TypeScript、实际搜索/历史/返回/焦点、无JS、701/720/750/960/1024宽度及短片回归。片集使用quick方式：主动播放、前后拖动、片尾、互斥播放及全部详情检查，不宣称重新完整观看每支影片。

新增可重复浏览回归为 `scripts/verify-browsing.mjs`，使用已有Playwright，通过参数指定入口和证据目录，不安装依赖或触碰个人会话。公开验收及精确版本统一记入发布回执与CURRENT。
