# Hi 排版与画廊精修 · 2026-10-03

方帅在 03 单色字徽发布后追加要求：「从 taste 角度来看，也把我的网站审美优化一下」「可以用 design 的 skill 或者任何你想到的方法」。本轮用 Product Design 的审阅方法，在既有设计系统内做比例、换行与字级精修，保留已选字徽、颜色、真实封面与作品顺序。

## 现状审阅

本轮重新捕获正式站 1440×1100、390×844 的页面作为 before，对照本地相同视口 after。截图是实际浏览器渲染；没有生成或重绘作品封面。

1. **首页 / 可用，视觉权重偏重**：口号 600 字重、最大116px，比问候和作品强很多。调整至500、最大104px，问候24px；首屏上下留白收至48/44px，作品更早出现。
2. **作品入口 / 清楚，分隔重复**：作品标题和分类各带一道横线。去掉标题下的线，保留筛选基线。标题用宋体，筛选与简介用无衬线；桌面作品名25px，封面圆角2px。
3. **手机 / 无溢出，口号过紧**：原来的三词挤在一行。改为 `Taste. Build.` / `Sell.` 两行，390px字号46.8px；通过局部减少上下留白平衡新增高度。保留手机单栏大图。

覆盖到的访问性检查包括：页面不横向溢出、键盘主题菜单与 Escape、分类/返回状态、无 JS 下作品可见。未据此声称完整 WCAG 合规或真实用户转化提升。

[前后对照](comparison.png)；原尺寸：[桌面 before](before-desktop.png) / [桌面 after](after-desktop.png)，[手机 before](before-mobile.png) / [手机 after](after-mobile.png)。

- **文案**：规范空白后，前后全部可见文字完全一致；没有新增口号、营销声明或装饰标签。
- **布局**：仍为开放双栏 / 手机单栏；13 件作品与既有排序、页面和体验链接保留。
- **字体**：只调整口号字重/比例、移动换行和信息字体分工；Geist / 中文宋体继续自托管。
- **配色与标识**：站点 token、单色03字徽、深浅色逻辑保持原样。
- **图片**：继续8:5、contain和原始文件；没有裁掉画纸、设备或作品内容。独立审阅指出封面内部留白仍不完全一致，本轮保留真实内容，未统一硬裁切。
- **行为**：筛选、历史/返回、主题持久化、Escape、logo回首页与无JS回退均保留。

这是对现有已选视觉系统的小范围精修，没有更换主题或重建整站。独立视觉审阅认为整体有改进，没有必须修复的视觉问题；偏好与长期效果仍由实际使用校准。
