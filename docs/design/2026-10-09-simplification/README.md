# Hi · 减少首屏与页尾的重复表达

2026-10-09。用户明确反馈上一版“整体我对这个页面设计的品味很不满意”“已经优化好几轮了”，要求参考 Apple，统一 Taste / Build / Sell 的字体字号和单行排列，移除冗余介绍、计数与入口，整理 footer。此前内部视觉评审的正面判断已被这次真实反馈否定；本次实现与测试通过也不代表用户已认可审美。

## 依据与取舍

实看 [Apple Mac](https://www.apple.com/mac/)（2026-10-09，1440 × 1000）：单一清晰标题、作品/产品作为主要视觉内容、工具与正文分层、有限的辅助文字。当前 Apple 页面还有产品导航、商店条款及完整站点目录，Hi 没有这些信息规模，未照搬。参照截图见 `apple-mac-desktop.webp`；只借鉴组织机制，没有复制其素材或代码。

旧版双列首屏将巨大 Taste、小号 Build/Sell、右侧自我介绍分成三个不连贯焦点；数字、序号与“可体验”又重复说明同一作品集。新的首屏只有一个居中 h1，三个词统一自托管 Instrument Serif 斜体，同字号、同基线，接分类/搜索和原作品。删除介绍而不另造口号。正常 320px 起单行；用户扩大文字时可按词换行，避免裁字。字体失败使用匹配字宽的本机 Georgia Italic 回退，首页预加载标题字体。

删除可见“作品 / 2026 / 17件作品”行、分类计数、卡片编号、与体验入口重复的可体验/可阅读/已上架状态；保留屏幕阅读器区域标题、搜索结果播报，以及内测/探索这类会改变访问预期的状态。17件作品、展陈顺序、完整图片和视频、内容与实际体验链接保留。

关于保留“慢慢做，认真玩。”及已选掌心之光，只留一句说明。Footer 改为小号 fangs. 与 Email / GitHub / 格得 / 柚子的小岛；删除第二个字徽、重复邀聊和回顶入口。桌面一行，手机署名与链接分两行；#contact 和跨站互链继续有效。
