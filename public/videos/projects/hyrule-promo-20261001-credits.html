海拉鲁 · 蓝焰余响

受《塞尔达传说》启发的个人非官方网页 Demo。宣传片使用当前 Demo 的真实 3D 运行画面，经剪辑呈现跃崖滑翔、蓝焰收集与磁力机关。此作品与任天堂无关联；相关角色、名称与标识归各自权利人。

画面

  • 营地、地形、溪流、滑翔帆与第一视角近似模型：项目原创程序几何与材质。
  • HUD：chaos-xxl / zelda-hyrule-ui 0.4.0（代码 MIT）。其 UI 图标与字体注明来自 Hunter Paramore 的 Zelda BOTW UI Kit，CC BY 4.0；界面在本项目中组合与调整，字幕另行添加。
  • 远行区树木、岩石、塔楼和石墙：Kenney Castle Kit 2.0，CC0。
  • 宣传字幕使用本机宋体栅格化，字体文件未随视频分发。

声音

配乐：“Town3 - Sunshine Coast”，Juhani Junkala / SubspaceAudio，JRPG Pack 2 Towns，CC0 1.0。为本片截取、调低音量并淡入淡出。风声为确定性合成。配乐与风声是重建声轨，并非现场录音。
